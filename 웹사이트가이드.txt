공유 썸네일 점검
- 대표 이미지는 assets/images/social/og-image.jpg 를 사용합니다.
- 권장 규격은 1200x630 JPG, 500KB 이하입니다.
- 대표 이미지를 바꾼 뒤에는 배포 완료 후 카카오톡에 https://koyuje-website.vercel.app/ 링크를 직접 보내 썸네일을 확인합니다.
- 카카오톡에서 이전 이미지가 계속 보이면 카카오 디벨로퍼스 공유 디버거에서 URL 캐시를 초기화한 뒤 다시 확인합니다.
- 카카오 공유 디버거: https://developers.kakao.com/tool/debugger/sharing
- 트위터/X는 운영 채널이 아니므로 twitter 메타 태그는 추가하지 않습니다.

검색 등록 확인 링크
- 네이버 서치어드바이저: https://searchadvisor.naver.com/
- 제출 사이트맵: https://koyuje-website.vercel.app/sitemap.xml
- 제출 후 네이버에서 site:koyuje-website.vercel.app 으로 색인 여부를 확인합니다.

검색/플레이스 등록용 소개 문구
- 짧은 소개: 공주 한옥에서 하루 두 팀만 촬영하는 프리미엄 돌사진·가족사진 스튜디오입니다.
- 긴 소개: 고유재 한옥스튜디오는 충청남도 공주시 전통 한옥 공간에서 아기의 첫 생일과 가족의 시간을 기록하는 프리미엄 돌사진·가족사진 스튜디오입니다. 실크 한복, 고즈넉한 한옥 분위기, 1:1 전담 디렉팅으로 하루 두 팀만 프라이빗하게 촬영합니다.
- 핵심 키워드: 공주 돌사진, 공주 한옥스튜디오, 공주 돌촬영, 충남 돌사진, 가족사진, 한옥 돌사진, 실크 한복 촬영

예약폼 테스트 제출 기준
- 테스트 제출 시 아기 이름은 테스트아기, 보호자명은 테스트보호자로 입력합니다.
- 휴대폰 번호는 실제 고객 번호와 겹치지 않도록 내부 확인용 번호를 사용합니다.
- 제출 후 예약 현황 조회와 관리자 화면 반영을 확인한 뒤, 관리자에서 테스트 예약임을 구분해 정리합니다.

최종 운영 전 체크리스트
- 홈 첫 화면에서 영상/대표 이미지가 바로 보이는지 확인합니다.
- 모바일 하단의 카톡 가능일 문의, 입금 후 작성 버튼을 눌러 이동을 확인합니다.
- 예약 안내 페이지에서 예약금, 날짜 변경, 환불 안내 문구를 확인합니다.
- 입금 후 작성 페이지에서 아기 앨범형 선택 시 부모님 사이즈 입력란이 숨겨지는지 확인합니다.
- 가족 실내 앨범형 선택 시 부모님 키, 한복, 신발 사이즈 입력란이 열리는지 확인합니다.
- 예약폼 제출 전 필수값 누락 시 해당 입력 위치로 이동하는지 확인합니다.
- 예약 정보 제출 완료 화면에서 48시간 안내와 카카오톡 문의 안내가 자연스럽게 보이는지 확인합니다.
- 예약 현황 페이지에서 휴대폰 번호 8자리 조회 흐름을 확인합니다.
- 예약 현황 조회 결과가 없을 때 작성 직후 반영 전 안내와 카카오톡 문의 버튼이 보이는지 확인합니다.
- 관리자 페이지에서 예약 상태 변경과 형제 정보 표시를 확인합니다.
- 고객 직접 수정 기능은 만들지 않습니다. 수정 요청은 카카오톡으로 받은 뒤 관리자가 관리자 페이지에서 직접 반영합니다.

Apps Script 저장/조회 필수 필드
- 예약폼에서 보내는 추가 필드: siblingInfo, siblingShoes, momHeight, momSize, momShoes, dadHeight, dadSize, dadShoes, address, channel, photoUsageConsent, memo
- 관리자 화면에서 "Apps Script 응답 누락"으로 표시되면 고객 미입력이 아니라 doPost 저장 또는 doGet admin 응답 매핑에 해당 키가 빠진 상태입니다.
- 작성 완료 메일 발송은 Apps Script의 MailApp.sendEmail 또는 GmailApp.sendEmail로 가능합니다. 고객 이메일과 스튜디오 이메일을 각각 수신자로 보내거나, 스튜디오를 cc/bcc로 넣는 방식으로 구현합니다.
